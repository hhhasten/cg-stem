# Журнал використання генеративного ШІ

Файл ведеться згідно з «Політикою щодо генеративного ШІ» методичних рекомендацій.
Кожне звернення до генеративних інструментів фіксується окремим записом.

| Поле | Значення |
|---|---|
| Здобувач | заповнюється |
| Формат виконання | заповнюється (індивідуально або команда) |
| Репозиторій | заповнюється |
| Інструмент за замовчуванням | OpenCode, агент для роботи з кодом |

## Запис № 1

- **Дата:** 2026-11-18
- **Інструмент:** OpenCode, модель DeepSeek V4.1 Flash
- **Задача:** створити каркас репозиторію для STEM-проєкту.
- **Ключовий запит:** «створи папку cg-stem-proj і структуру папок під проєкт з обробки зображень».
- **Згенерований результат:** структура каталогів, файли `.gitignore`, `README.md`,
  `META-USAGE.md`, `requirements.txt`, початковий git-коміт.
- **Внесені зміни:** вручну скорочено README, переписано журнал під власний формат,
  прибрано зайві файли-заглушки.
- **Метод верифікації:** перевірено перелік файлів у git, запуск не потрібен.
