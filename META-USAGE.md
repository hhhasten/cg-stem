# Журнал використання генеративного ШІ

Файл ведеться згідно з «Політикою щодо генеративного ШІ» методичних рекомендацій.

## Запис № 1

- **Дата:** 2026-11-19
- **Інструмент:** OpenCode, модель DeepSeek V4.1 Flash
- **Задача:** створити початковий каркас проєкту.
- **Ключовий запит:** «створити структуру каталогів для STEM-проєкту з обробки зображень».
- **Згенерований результат:** структура каталогів, `pyproject.toml`, `README.md`,
  `AGENTS.md`, `.gitignore`, перший коміт.
- **Внесені зміни:** правила проєкту скорочено до одного файлу, зайві каталоги прибрано.
- **Метод верифікації:** перевірка дерева файлів, `pip install --dry-run`, чистий `git status`.

## Запис № 2

- **Дата:** 2026-11-19
- **Інструмент:** OpenCode, модель DeepSeek V4.1 Flash
- **Задача:** зафіксувати технічне завдання і підготувати перевірку вибірки.
- **Ключовий запит:** «скласти ТЗ для проєкту з обробки відбитків пальців».
- **Згенерований результат:** `docs/tz.md`, `scripts/check_dataset.py`, розділ «Дані» в README.
- **Внесені зміни:** перелік методів скорочено до шести, пороги метрик позначено як орієнтовні.
- **Метод верифікації:** запуск скрипта на порожньому каталозі.

## Запис № 3

- **Дата:** 2026-11-19
- **Інструмент:** OpenCode, модель DeepSeek V4.1 Flash
- **Задача:** зафіксувати вибірку маніфестом і прискорити перевірку даних.
- **Ключовий запит:** «побудувати маніфест вибірки з SOCOFing, перевіряти лише вибрані файли».
- **Згенерований результат:** `cgstem/dataset.py`, `cgstem/paths.py`,
  `scripts/build_manifest.py`, доопрацьований `scripts/check_dataset.py`.
- **Внесені зміни:** спільну функцію шляхів винесено в `paths.py`, перевірку розміру
  додано до відбору, кількість записів контролюється перед записом.
- **Метод верифікації:** повторна побудова маніфесту з однаковим sha256,
  перевірка 200 файлів, `pylint`.
