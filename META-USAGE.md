- **Задача:** створити початковий каркас проєкту.
- **Ключовий запит:** «створити структуру каталогів для STEM-проєкту з обробки зображень».
- **Згенерований результат:** структура каталогів, `pyproject.toml`, `README.md`,
  `AGENTS.md`, `.gitignore`, перший коміт.
- **Внесені зміни:** правила проєкту скорочено до одного файлу, зайві каталоги прибрано.
- **Метод верифікації:** перевірка дерева файлів, `pip install --dry-run`, чистий `git status`.
