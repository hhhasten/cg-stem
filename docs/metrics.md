# Метрики якості зображень

Три метрики відповідають на одне питання: наскільки оброблене зображення
відрізняється від вихідного. Різниця в тому, як саме рахується відхилення.

## MSE

Середньоквадратична похибка між двома зображеннями однакового розміру:

```
MSE = (1/N) * Σ (I(i) - K(i))²
```

- I оригінал, K результат, N кількість пікселів.
- Діапазон від 0 до 65025 для 8 біт.
- 0 означає повний збіг.
- Квадрат не дає різницям різного знаку скоротитися і сильніше штрафує великі
  відхилення.

Приклад: різниці пікселів 0, 1, 2, 3 дають MSE = (0 + 1 + 4 + 9) / 4 = 3.5.

## PSNR

Та сама похибка, переведена в децибели:

```
PSNR = 10 * log10(MAX² / MSE)
```

MAX дорівнює 255 для 8-бітних зображень.

- Ідентичні зображення дають нескінченність, оскільки MSE = 0.
- Кожні 10 дБ означають похибку в 10 разів меншу.
- 30 дБ відповідає помітній зміні, 40 дБ візуально майже не відрізняється.

Обмеження: метрика не враховує структуру. Зсув зображення на один піксель
обвалює PSNR, хоча око різниці не бачить.

## SSIM

Порівнює локальну структуру у вікні 11x11, яке проходить по зображенню.
У кожному вікні враховуються яскравість, контраст і структура:

```
SSIM = ((2μxμy + C1)(2σxy + C2)) / ((μx² + μy² + C1)(σx² + σy² + C2))
```

μ середні, σ² дисперсії, σxy коваріація, C1 і C2 константи стабільності.
Підсумкове значення є середнім по всіх вікнах.

- Діапазон від -1 до 1, де 1 означає повний збіг.
- 0.9 і вище: різниця непомітна.
- 0.7: помітна втрата якості.
- 0.5 і нижче: структура сильно зруйнована.

Краї карти подібності відкидаються, бо там вікно виходить за межі зображення.
Мінімальний розмір зображення для SSIM дорівнює 11x11.

## Застосування в проєкті

| Метод | Метрики |
|---|---|
| Медіанний, гаусів, CLAHE | PSNR, MSE, SSIM відносно оригіналу |
| Метод Оцу, морфологія | частка переднього плану, кількість компонент |
| GLCM | контраст, енергія, гомогенність, кореляція |

Для бінарних масок PSNR і SSIM не застосовуються: дисперсія стрибає між 0 і 255,
і метрика втрачає сенс.

## Приклад на реальному знімку

Відбиток пальців 96x103, розмиття гаусом 5x5 із sigma 1.0:

```
PSNR = 13.2 дБ
SSIM = 0.468
```

Низький PSNR тут не означає поганий фільтр. Ядро змінило кожен піксель, а гребні
відбитка шириною близько 9 пікселів втратили контраст.

## Як інтерпретувати результати

Метрики вимірюють відхилення від оригіналу, а не покращення. Чистого еталона без
шуму в наборі немає, тому коректне формулювання таке: медіанний фільтр змінює
зображення слабше за гаусів і при цьому прибирає імпульсний шум.

Найцінніші висновки там, де метрики розходяться. Високий PSNR при низькому SSIM
означає, що зображення стало гладким, але деталі втрачено.

## Питання на захист

- Чому PSNR дорівнює нескінченності для однакових зображень: MSE = 0.
- Чому не можна порівнювати PSNR зображень різного розміру: похибка усереднюється
  по пікселях, структура помилки різна.
- Чому для масок не рахують SSIM: формула розрахована на яскравість і контраст.
- Навіщо обрізати краї в SSIM: біля межі вікно неповне, значення недостовірні.
