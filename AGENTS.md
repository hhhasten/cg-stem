# AGENTS.md

Правила роботи над цим репозиторієм. Файл обов'язковий для агентів і корисний
для людей.

## Мова

- Документація, README, звіт: українська.
- Ідентифікатори в коді: англійська.
- Докстрінги, повідомлення про помилки: українська.

## Коментарі

- Інлайн-коментарів у коді не пишемо.
- Докстрінг обов'язковий для кожної публічної функції та класу, один рядок.
- Місце, де коментар справді потрібен, пропонується окремо перед комітом.

## Читабельність

- Жодних конструкцій, що скорочують код ціною ясності: вкладені генератори,
  лямбди в ланцюжках викликів, кілька виразів через крапку з комою, вкладені
  тернарні вирази.
- Простий генератор одного рівня дозволений: `[px for px in row if px > threshold]`.
- Один рядок містить одну дію.
- Робота з numpy: одна формула на рядок, проміжні результати в іменованих змінних.
- Замість коментаря обираємо зрозумілу назву або окрему функцію.

## Файли

- Файли тримаємо невеликими: модуль до 150 рядків, функція до 30.
- Споріднені методи однієї категорії живуть в одному модулі
  (`methods/filtering.py`, `methods/segmentation.py`).
- Новий файл створюємо, коли модуль розростається або в нього з'являється
  окрема відповідальність, а не за принципом «один метод = один файл».
- Спільний код виноситься в окремий модуль, щойно його використовують два методи.
- Дублювання логіки не допускається.

## Типізація

- Публічні функції та методи мають анотації параметрів і результату.
- Локальні змінні, лічильники циклів і проміжні масиви не анотуються.
- Перший рядок кожного модуля: `from __future__ import annotations`.
- Типи зображень беруться з `cgstem.types`: `Image`, `GrayImage`, `FloatImage`, `Mask`.
- `Protocol`, `TypedDict`, дженерики та перевантаження не використовуємо.
- `mypy` не обов'язковий; якщо запускається, то лише для `src`.

## Параметри

- Параметри методів задаються в YAML-конфігу або аргументах CLI.
- Зміна параметра не потребує зміни коду.

## Межі методичних рекомендацій

- Заборонені бібліотечні реалізації алгоритмів обробки.
- OpenCV і Pillow: лише читання, збереження, показ зображень.
- numpy дозволений для роботи з масивами, а не як готова реалізація методу.
- Методи не повторюють лабораторні роботи № 5 і № 6.

## Документація

- Лаконічно, без тавтології, емодзі та довгих тире.
- Кожне звернення до генеративних інструментів фіксується в `META-USAGE.md`.
