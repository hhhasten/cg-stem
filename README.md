# cg-stem-proj

STEM-проєкт: обробка та аналіз зображень класичними методами комп'ютерної графіки
(фільтрація, гістограмні перетворення, сегментація, морфологія, аналіз текстур).

Усі алгоритми реалізовані вручну. OpenCV та Pillow використовуються лише для
введення/виведення і візуалізації зображень. Методи ШІ та машинного навчання
не застосовуються.

Стан: усі шість методів реалізовано, лишилися пайплайн, CLI і звіт.

## Структура

```
cg-stem-proj/
├── pyproject.toml           # метадані пакета, залежності, налаштування інструментів
├── configs/                 # YAML-конфіги методів і пайплайнів
├── data/
│   ├── raw/                 # повний датасет (локально, не в git)
│   ├── manifest.tsv         # фіксована вибірка 200 знімків
│   └── reference/           # еталони для тест-кейсів
├── src/cgstem/
│   ├── types.py             # спільні типи зображень
│   ├── paths.py             # шляхи проєкту
│   ├── dataset.py           # маніфест вибірки
│   ├── io/                  # завантаження та збереження зображень
│   ├── ops/                 # згортка та ядра
│   ├── methods/             # методи за категоріями, один модуль на категорію
│   │   ├── filtering.py
│   │   ├── histogram.py
│   │   ├── segmentation.py
│   │   ├── morphology.py
│   │   └── texture.py
│   ├── pipeline/            # стадії, запуск, збереження проміжних результатів
│   ├── metrics/             # PSNR, MSE, SSIM
│   └── cli/                 # розбір аргументів, точка входу
├── tests/                   # автотести з ручними розрахунками на 3x3 та 5x5
├── out/
│   ├── images/              # оброблені зображення
│   ├── stages/              # проміжні результати стадій
│   └── metrics/             # метрики прогонів (CSV, JSON)
├── docs/                    # ТЗ, документація, звіт
└── scripts/                 # допоміжні скрипти
```

## Вимоги

Python 3.10 або новіше.

## Встановлення

Проєкт використовує `uv`.

```
uv sync
```

Команда створює `.venv`, встановлює залежності та сам пакет у режимі розробки.
Залежності задані в `pyproject.toml`, точні версії в `uv.lock`.

Запуск команд у цьому середовищі:

```
uv run python scripts/check_dataset.py
uv run pytest
```

## Запуск

Розділ заповнюється після реалізації CLI.

## Дані

Вибірка: SOCOFing (Sokoto Coventry Fingerprint Dataset), Kaggle. Датасет
завантажується вручну і розпаковується в `data/raw/`. Каталог не комітиться.

Фіксована вибірка описана в `data/manifest.tsv`: 120 реальних знімків
(суб'єкти 1..12) і 80 змінених (суб'єкти 1..8, тип зміни `_Obl`). Маніфест
містить шлях, групу, суб'єкта, руку, палець, тип зміни та sha256 кожного файлу.

Побудувати маніфест заново і перевірити вибірку:

```
uv run python scripts/build_manifest.py
uv run python scripts/check_dataset.py --manifest data/manifest.tsv
```

Деталі в [технічному завданні](docs/tz.md).
